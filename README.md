# 🎬 Co-Stream

**Watch free webseries and movies of any OTT platform without any ads.**

Co-Stream is a modern, ad-free streaming app built natively for Android using Jetpack Compose and AndroidX Media3 (ExoPlayer). Stream your favorite movies, web series, and TV shows with a clean, immersive cinema player interface.

---

## ✨ Features

- 🚫 **100% Ad-Free Experience**: Stream seamless content without interruptions or ads.
- 🍿 **All-in-One Catalog**: Discover movies and web series from top OTT platforms in one place.
- ⚡ **Next Episode Autoplay / Skip**: One-tap next episode button for seamless series binge-watching.
- 🔍 **Universal Search & Filters**: Search catalog by title, genre, and platform.
- 📱 **Edge-to-Edge Immersive Video Player**:
  - Full cutout & notch support in both landscape and portrait orientations.
  - Pinch-to-zoom (Fit / Fill aspect ratio toggle) with real-time feedback.
  - Dedicated center playback controls (Seek -10s, Play/Pause, Seek +10s).
  - Vertical gesture controls for brightness (left) and volume (right).
  - Screen orientation toggle & screen lock.
  - Picture-in-Picture (PiP) support.
  - Audio and subtitle track selection + playback speed adjustment.
- 💾 **Offline Download**: Save movies and episodes directly to device storage for offline playback.
- 🔖 **My List & Watch History**: Keep track of what you're watching and pick up right where you left off.

## 🛠️ Tech Stack & Architecture

- **UI**: 100% Jetpack Compose (Material 3)
- **Player Engine**: AndroidX Media3 (ExoPlayer with HLS & MP4 support)
- **Networking**: OkHttp 4
- **Image Loading**: Coil 3 (Compose)
- **Serialization**: Kotlinx Serialization JSON
- **Architecture**: MVVM with Android Architecture Components & StateFlow/Compose State
- **Min SDK**: Android 8.0 (API level 26)
- **Target SDK**: Android 15 (API level 36)
